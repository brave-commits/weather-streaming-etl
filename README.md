# Weather Streaming ETL

This project is an ETL (Extract, Transform, Load) pipeline for streaming weather data using Python and Docker.

## Features
- Real-time weather data ingestion
- Docker-based deployment
- Configurable pipelines for data processing

## Requirements
- Python 3.x
- Docker
- Docker Compose

## Setup
1. Clone the repository: git clone https://github.com/brave-commits/weather-streaming-etl.git

## Running the Pipeline
To start the pipeline, use the following command: run.py
